## 公众号摘要

### 标题：铁路轨道及植被入侵检测数据集｜2类目标，多格式标注

正文摘要：
本数据集为铁路巡检场景目标检测数据集，实拍铁路沿线图像，包含轨道本体、轨道周边植被入侵两类标注目标。图像分辨率1152×2048，共1341张，划分训练/验证/测试子集，配套YOLO、VOC、COCO三种通用标注文件。可训练模型识别轨道范围、检测侵入限界的杂草灌木，助力无人机/轨道监控自动巡检、铁路安防预警、科研实验模型训练。

### 精简封面摘要

铁路轨道与植被入侵目标检测数据集，1341张高分辨率图像，2类标注，支持YOLO/VOC/COCO，适用于铁路入侵物智能巡检。
